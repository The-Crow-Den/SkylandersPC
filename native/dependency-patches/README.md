# Historical renderer patches

These patches record the renderer changes made before the renderer became the
project's own component, now `renderer/` in this repository. They are kept as
the public record of those early modifications: `bbport-local-changes.patch`
first, then the menu and remaining changes, then `parallel-pipeline-preload`,
`compile-split-counters` and `pipeline-prefetch`. New renderer changes are
commits to `renderer/`, not new files here.
`bbport-local-changes.patch` stays as the hash-pinned provenance record in
`LICENSES/bbport-source.json`.
