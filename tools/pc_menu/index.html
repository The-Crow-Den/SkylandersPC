Display

Fullscreen uses the display the game window is on.

The game renders at this resolution; a different window or screen size scales the picture.

Button icons change in the game after Apply settings and restart. Automatic matches the controller connected at launch.

Controller: LB jumps to the tabs on the left, RB to the panel on the right. D-pad or left stick moves, A selects, B goes back, Start closes. Keyboard: arrows, Enter, Escape (back), Page Up / Page Down (tabs / panel), F6 closes, F10 minimizes the game.

Portal voices play through your PC speakers.

Some settings apply after restart.
